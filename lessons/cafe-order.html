逐句翻譯

  • 你好，請給我一杯熱美式咖啡。
  • 好的，一杯熱美式咖啡。請問是在店裡喝，還是外帶呢？
  • 我在這裡喝。多少錢？
  • 是 4,500 韓元。
  • 我用卡付。請稍等一下，卡在這裡。
  • 謝謝。請慢慢享用！

文法講解

1. 數量詞「數詞 + 量詞」：表示數量

是什麼：韓語說數量時，順序是「名詞 + 數字 + 量詞」。句型結構：名詞 + 數詞 + 量詞（잔：杯、個：개、名：명）。短文例句：아메리카노 한 잔 주세요。（請給我一杯美式咖啡。）再舉一例：커피 두 잔 주세요。（請給我兩杯咖啡。）容易錯的地方：不要把數字放在名詞前面，說「한 잔 아메리카노」是錯的；韓語的順序和中文「一杯美式咖啡」剛好相反。

2. -(으)로：表示方法、手段

是什麼：表示方法、手段，意思像「用……、以……方式」。句型結構：名詞 + -로 / -으로；母音結尾用 -로，子音結尾用 -으로。短文例句：카드로 할게요。（我用卡付。）再舉一例：버스로 가요。（我坐公車去。）容易錯的地方：不要和表示地點的 -에서 搞混；-로 是「用什麼方法」，-에서 是「在哪裡」，例如「在咖啡店喝」要說 카페에서 마셔요，不是 카페로 마셔요。

3. -ㄹ게요：表示自己的意願

是什麼：表示說話者自己的意願或打算，意思像「我會……、我來……」。句型結構：動詞詞幹 + -ㄹ게요（母音結尾）/ -을게요（子音結尾）。短文例句：여기서 마실게요。（我在這裡喝。）再舉一例：내일 전화할게요。（我明天會打電話。）容易錯的地方：-ㄹ게요 只能說自己的動作，不能用來說別人的動作；問別人要不要做某事時，要用 -ㄹ까요，例如「一起去嗎？」要說 같이 갈까요?

常用詞彙

  • 아메리카노 美式咖啡（a-me-ri-ka-no，五個音慢慢讀）—— 아메리카노 한 잔 주세요。（請給我一杯美式咖啡。）
  • 따뜻하다 熱的、溫暖的（tta-tteu-ta-da，第一個音是緊音，輕輕帶過）—— 따뜻한 아메리카노（熱美式咖啡）。
  • 차갑다 冷的、冰的（cha-gap-da，讀音像「恰嘎達」）—— 차가운 거요?（要冰的嗎？）
  • 매장 店內、店鋪（mae-jang，讀音像「妹將」）—— 매장에서 드세요?（在店裡喝嗎？）
  • 가져가다 帶走、外帶（ga-jyeo-ga-da，慢慢讀）—— 가져가세요?（要外帶嗎？）
  • 얼마 多少錢（eol-ma，讀音像「喔媽」）—— 얼마예요?（多少錢？）
  • 카드 卡、信用卡（ka-deu，讀音像「卡的」）—— 카드로 할게요。（我用卡付。）
  • 맛있게 드세요 請慢慢享用、請吃好喝好（ma-sit-ge deu-se-yo，慢慢讀）—— 맛있게 드세요!（請慢慢享用！）

跟讀小提示

先一句一句斷開讀，逗號的地方停一下；數字「4,500원」讀作「사천오백 원」，慢慢讀就好；問句「얼마예요?」「가져가세요?」的句尾要輕輕揚起，像真的在問對方一樣。
